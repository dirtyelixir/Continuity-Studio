# 公共、章節 Scene 與聲音資產

「角色與場景」先顯示公共身份，再按章節 → Scene 顯示實際使用的角色、地點、道具與聲音。主角預設應明確標為公共，第一章開始便可跨主線沿用。公共身份不代表每一場都出現；Scene 只列其實際引用。同一 canon ID 永遠使用同一份資料與參考圖，不因分組複製圖片。

資產設定提供公共、章節 Scene、自動三種所屬。自動模式將跨多個已採用章節使用的身份列為公共；明確選擇優先。舊作品可直接讀取，未被任何場使用的項目列入未分配。單純修改所屬不使已批准圖片失效。

只聞其聲、從未出鏡的人物使用 `kind=voice`：顯示聲音設定、原有試音與後製配音入口，沒有圖片生成或匯入操作。後端亦拒絕為此類身份建立圖片任務。其 canon ID、對白、音色、時間及狀態仍保留，但不佔圖片參考名額，不列為缺少人物圖片，也不綁到可見人物的嘴形。收音機、電話等實際可見設備仍為道具；有出鏡身份的人物在部分鏡頭畫外說話，仍保留原人物身份。

新劇情與分鏡請求包含上述分類規則。分類依劇本而定，不能只因有台詞便推定需要人物四視圖。H3 聲音提示保留原有對白，並明確標示聲源不可見，不憑空添加臉、身體或圖像參考。

`scope` 僅為組織資料，從圖片依賴和英文分鏡準備來源 hash 中排除。既有不含 scope 的準備結果可沿用；過渡期間含 scope 的任務只有完整來源及 hash 可驗證、其餘內容完全一致才可沿用。將角色改為 voice 是實質製作變更，相關場景提示詞仍需更新。匯出包含 `asset-groups.json`，可攜帶公共／章節／Scene 引用關係。
