# 角色 reference：固定四視圖

每個 character 使用一張四格身份參考板，順序與使用者提供的圖片一致：

1. 正面面部及上身近鏡，第一格稍寬。
2. 向畫面左方的側面全身。
3. 向畫面右方的側面全身。
4. 背面全身。

最後三格由頭到腳完整入鏡，保持相同比例與落地高度。四格是同一角色，同一套服裝、髮型、身體比例及材質；左右不對稱的配件要符合身體方向，不可簡單鏡像。使用淺色中性背景、細分隔線，不加標題或文字。原有動畫、布偶、機械人等製作畫風繼續有效。

使用者排版圖保存於 `data/guides/character-four-view.png`。生成及審查時會獨立附上，只控制版面；圖中的男士、服裝及寫實畫風不屬於任何故事角色。全資料夾備份包括這張原始示例；ZIP 亦包含 `reference-guides/character-four-view.png` 和本格式要求。

## 使用

打開 **角色與場景**，頁面標題是「角色四視圖與場景設定」。角色卡按 **製作新版四視圖** 或 **生成角色四視圖**；也可 **匯入四視圖**。製作新版時會帶入該角色已批准的原圖以保留身份。**補齊參考圖** 亦會補做尚未通過四視圖要求的角色，已有待審候選則不重複啟動。

Astra 會實際審查四格內容、次序、全身完整度與身份一致性。四視圖通過審查後可直接批准；未通過或尚無審查結果時，可按 **人工確認採用**，閱讀問題，再按 **確認採用此圖**。不需填寫欄位，系統自動保存人工覆核記錄，原審查結果不會改為通過。舊設定或失效參考圖的限制仍然有效。

新檔名例如：

```text
assets/The Smallest Fix/Characters/Ada/Ada-four-view-v001.png
assets/The Smallest Fix/Characters/Pip/Pip-four-view-v001.png
```

以上是新候選的命名規則，檔案只在實際生成或匯入後才存在。圖像旁保存提示詞、來源及審查記錄；新版本不覆蓋舊圖。

## 既有作品

舊角色圖會標示「四視圖待更新／審查」，不會假稱已轉成四視圖。它們保留身份來源與舊分鏡的可追溯關係。新四視圖經使用者批准後才取代舊的 approved reference，相關分鏡按既有規則標示 stale。格式規則更新本身不會更改原圖、撤銷批准或自動啟動生成。

分鏡與 Ref2VA 使用四視圖中的同一個角色身份，不會將四格排版、四個副本帶入故事畫面。地點、道具及首尾幀仍使用各自原有的單幅圖要求。
