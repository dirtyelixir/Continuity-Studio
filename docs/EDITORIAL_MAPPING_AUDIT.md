## 修正的流程缺口

| 位置 | 原問題 | 現在行為 |
|---|---|---|
| 採用 | 自己採用後 base hash 改變，頁面反而標示過時 | 以已採用方案版本及目前 Scene 內容識別正式狀態；重複採用相同版不增版本 |
| 正式儲存 | Production 和聲音註解分開寫入 | 正式版、Scene 聲音、來源對照及剪接歷史同一交易保存；失敗全部回滾 |
| 場景間修改 | 整份旧快照可能覆蓋其他場景新修改 | 只合併本場景剪接；目前 Production revision 必須一致 |
| 導演審查 | 未讀取已保存的獨立聲音／故事狀態註解 | 審查凍結同版註解，核對合法 J/L-cut、說話者、無聲口形及身份證據；審查 freshness 包括此內容 |
| 正式 ZIP | 聲音時間表只留在試行設定 | `edit/audio-timeline.json` 與 `production.json.editorial` 一致，含整份作品時間、場景時間及舊→新 Shot/frame 對照 |
| 下游入口 | 返回影片頁未必選到當前 Shot | 「製作這個 Shot」同時帶作品及 Shot ID；比較舊版不顯示無效製作入口 |
| 其他作品／場景 | 入口只能使用硬編碼試行 | 可從目前正式 Shots 建立可編輯候選，沿用現有對白；不虛構已做新戲劇判斷 |

## 對應原則

Scene 只擁有 Scene 全域提示詞；Shot 擁有自己分鏡、生成模式、關鍵幀及對白。剪接列以 `shot_id` 引用來源，另保存 planned_edit_in/out。同一來源可多次取用，不能依剪接顯示序號尋找圖片或影片。新拆 Shot 有新 ID 和關鍵幀 ID；來源舊→新對照是追溯資料，不是自動批准舊媒體重用。

已批准圖片須符合 target dependency hash。生成中的舊 frame 即使稍後完成，也只保存為舊／stale 候選，不能套落新的 frame。H3、Scene/Shot prompt regeneration、影片做法建議及已採用影片各自核對來源版本。已刪除或變更 Shot 的配音選擇保留作歷史，匯出只使用 selected、succeeded 且 current 的 take。

聲音 cue 維持來源 Shot、原文對白、說話者、來源時間及原有 delivery；可移動成片位置，不能悄悄改口形為有聲或改說話者。畫面重排後聲音不自動跟著移動，介面明示需一併核對。整份作品匯出將場景秒數加上此前剪接長度；不相連場景或失效註解不輸出可執行聲音 cue，並附警示。

`editorial_scenes:<project>` 是每 Scene 已採用註解；既有 `editorial_applied` 自動相容讀取。Scene hash 包括此 Scene、Shots、剪接、所用 canon 和 style。其他 Scene 獨立變更不使本場失效；本場改手位、來源、時長等則要求重新核對。

## 尚未完成媒體的地方

文字／圖片預覽不是實際影片剪接。所有 range 仍是 planned_unverified。選中且仍有效的配音可對到不可變 take ID／音檔 hash，但未自動拉伸、裁剪或混音，長度仍需實際核對。沒有音檔時 audio_asset=null；口形標記不會冒充聲音。實際影片的構圖、動作、嘴形和可用入出點仍需媒體審查。

方法選讀仍限於 Studio-owned 的既有剪接知識；本次沒有宣稱所有自動分鏡已變成通用蒙太奇規劃器。
