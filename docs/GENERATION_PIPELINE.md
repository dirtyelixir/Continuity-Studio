# Adaptive generation arrangements

New non-manual `h3_group_plan` jobs freeze `generation-stages-v1` with the selected provider, context/output policy, full original source, methods, feedback and schema. Qwen uses its selected VRAM Manager gateway's chat template/tokenizer and runtime slot limit. Other providers retain the conservative UTF-8 byte bound; it is never labelled an exact token count. No automatic provider change or global settings change occurs.

The original single request is retained when it fits both the input check and a conservative output-sizing hint. Otherwise Studio recursively partitions contiguous edit uses. Each local call receives complete original linked shots, scene direction and applicable canon/board intent. The explicit phase contract preserves the complete edit order and assigns other source units to mandatory peer phases. Original source files and frozen input are never truncated or replaced with model summaries.

Every artificial split has a mandatory model reconciliation of the complete last left group and first right group. It may merge, repartition or retain these provisional groups according to creative intent. When the full boundary request does not fit, an explicit boundary projection omits only source keyframe descriptions already read in local calls; original timing, state, dialogue, action, sound, board image-use intent and complete provisional decisions remain. Validation always uses the full original source. Aggregate reasons, checks and per-image decisions remain in their groups; the final summary is deterministic.

Every request is checked before transport. A saved, explicit `finish_reason=length` permits recursive subdivision of a local multi-unit request. Ambiguous failures and invalid results stop; they never cause automatic re-submission. Explicit resume uses completed checkpoints or validates a complete raw response saved before interruption. Each attempt has its own directory and frozen identity. Completed local and boundary nodes, source/provider/schema identity, result hashes and a final receipt must all replay successfully before success or adoption. Missing boundaries, tampering, cancellation and stale-source resume are rejected. Old jobs and manual submissions retain their original contracts.

This is bounded adaptation, not unlimited capacity: a single complete source plus mandatory instructions or an indivisible group boundary can still exceed the selected budget. Boundary output exhaustion also stops with saved work intact. Increasing settings requires a new job; resume deliberately keeps the original frozen settings. The existing GroupPlan result limit and H3 execution constraints still apply. This planner does not split source videos into new executable segments.

Progress displays the current phase and saved batch count, with no invented total. Failed/interrupted current arrangements expose 接續安排. Technical receipts remain in job details. Evidence and limitations are recorded in `reviews/generation-adaptive-20260914/`.
