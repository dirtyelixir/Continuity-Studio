# 介面語言

Continuity Studio 的預設介面是繁體中文（`zh-Hant`），日期及時間使用 `zh-HK` 格式。品牌名稱 Continuity Studio、Astra、ComfyUI 與模型識別碼保留原樣。

介面範圍包括導航、製作手冊、角色與場景、分鏡、審查室、Ref2VA 與首尾幀提示詞頁、活動與版本、製作資料夾、設定、表單、提示訊息和常用錯誤。狀態及功能名稱只在顯示時翻譯；API、資料欄位、工作狀態代碼、DOM 操作識別碼及已保存的路徑不改名。

Scene（場景）、Shot（鏡頭）、Prompt（提示詞）、Picture／Subject 槽位標籤在適當位置保留，方便對照 ComfyUI。JSON 詳情仍顯示原始欄位及結果，供核對或手動提交。

原有作品名稱、劇本、對白、角色描述、提示詞、使用者備註及服務商生成內容保留原文。介面中文化不會重寫創作內容、重新生成素材或改動批准狀態。自訂服務商及外部技能的名稱與描述按其原始資料顯示。

`static/locale-zh.js` 集中管理狀態／功能名稱及常用錯誤。未知的第三方錯誤會顯示繁中說明並保留原始技術診斷，避免隱藏錯誤資訊。

## 產品來源

此專案的製作工作流程、頁面、資料結構與程式碼是按使用者提供的產品要求建立。它使用 FastAPI、SQLite 等既有開源技術，並整合 Astra／Codex 和 ComfyUI 工作流程；不是把另一套現成製作應用程式換名。這段說明描述實作來源，沒有對品牌名稱的獨佔性或法律權利作判定。
