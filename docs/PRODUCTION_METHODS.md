# Studio 既定製作方法

Studio 現在擁有並強制載入共用製作方法；切換 Astra、DeepSeek 或其他已接通的服務商，不會讓模型自行決定是否使用。這是把既定規格、範例及驗證保存成可執行流程，並不等於複製 Astra 的全部理解或創作能力。

## 已實作的行為

- `studio/bundled/studio-production-methods/` 保存核心 SKILL.md、故事／分鏡、圖片、角色四視圖、H3 和審查規則。全部 15 項內建功能都有路由；額外功能至少載入共用核心。相關既有專門規則仍會合併。
- 程式在呼叫服務商前加入適用規則，保存版本、檔案 SHA256 及完整指令。檔案與固定 manifest 不符會阻止新工作開始。這套方法不能在一般擴充技能開關中停用。
- 圖片整理模型回傳有限的結構化欄位。Studio 驗證欄位，組合目標、參考用途、外觀、構圖、光線及固定製作約束，再把完整 prompt 交給選定圖片服務。Krea2／Klein 的文字編碼節點接收這段 prompt。
- 自動圖片工作的整理步驟同時載入適用於 `image` 和 `image_prepare` 的已啟用擴充技能，不會漏掉只標記後者的技能。
- HTTP 模型的未截斷原始結果會在格式驗證前保存，使既有分鏡單次修正流程也能用於 DeepSeek。截斷或空白結果仍會失敗。

## 已保存圖片 prompt 的沿用

相同作品、目標、來源、要求、完整指令／技能版本、參考用途及實際圖像位元組完全相符時，新圖片工作可直接沿用先前保存且可重新驗證的整理結果與 prompt，略過整理模型。單純改選整理模型不會造成重寫；前次圖片生成失敗，只要整理已有效保存，也可沿用。

改動要求、參考像素、來源內容、參考用途或規則會重新整理。傳輸需要參考拼板的差異也會分開處理。更換圖片服務後仍會依該服務的工作流執行；相同文字不代表不同圖片模型必然產生相同畫面。

此沿用機制適用於本版開始保存指紋的新工作。歷史工作缺少驗證資料時不會被自動視為可沿用。沿用的是已保存的文字，不代表該文字或生成圖片已獲使用者批准；需要新的創意方向時應寫入新的修改要求。

## 可檢查的記錄

「擴充功能與服務商」顯示強制套用狀態。新工作詳情顯示方法版本、整理來源／沿用的工作，以及送往圖片服務的最終 prompt。工作資料夾保留 `production-method.json`；作品 ZIP 的 `production-methods/used-methods.json` 匯出所用方法、指令及圖片 prompt 記錄。

修改核心規格時，需同步更新 manifest 的版本與檔案雜湊，跑相關測試並重啟 Studio。不要直接改已保存工作的指令來冒充原始來源。

## 驗證與質素界線

完整 Python 回歸：429 項通過；新增方法測試 16 項通過。涵蓋 Astra／DeepSeek 收到相同已組合指令、跨模型逐字沿用、變動失效、圖片生成失敗後沿用、固定約束、原始 HTTP 分鏡結果的單次修正。介面在隔離工作區切換 DeepSeek＋本機圖片並重新載入後仍顯示強制套用。

真實 Astra 用現有道具參考完成一次圖片 prompt 整理；產物及本機 Krea2 圖的文字節點精確對照保存在 `data/acceptance/production-methods/`。本次沒有提交新圖片／影片生成，也沒有更改作品或批准狀態。獨立技能情境檢查保留了手持物、開門前狀態、光線及來源限制。

DeepSeek 路徑目前是模擬 API 合約驗證，尚無已配置憑證及真實創作品質驗收。本次保證程式載入方法、驗證結構、加入固定規格及按條件逐字沿用；不能保證模型對每個新要求都具備 Astra 相同的判斷能力。新內容仍須檢查語意、連戲及實際畫面品質；原有審查／使用者採用流程保留。完整斷網／Astra 故障的全功能替代驗收仍須依 `ASTRA_OUTAGE_RESEARCH.md` 逐項完成。

## 表演推理增量（2026-09-13，v1.2.0）

新增 Studio 自有 `references/performance.md`，將人物目標、收到刺激、評估、控制、行動與餘波連成可見表演，套用於分鏡、逐鏡 H3 及文字審查。原有來源、對白、景別、時長、風格與輸出格式仍然有效。場景 global-only、圖片與模式選擇不載入整段表演推理。外部文件只作參考，執行不依賴 Downloads。

65 項相關測試與技能驗證通過；運行中的 API 已讀取 1.2.0。本次只改方法檔案，loader 每次重新讀取，毋須重啟；上文重啟要求適用於涉及 Python 程式載入的更新。現有全域方法雜湊會令依賴舊方法的準備／QC 需要更新，舊章節分階段工作不能跨方法續跑，須建立新方案，原階段記錄仍保存。沒有重寫已採用作品或生成媒體；尚未宣稱實際影片演出質素通過 A/B 驗收。
