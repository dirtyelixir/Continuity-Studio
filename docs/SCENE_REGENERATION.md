# 重新生成 Scene 全域提示詞

Scene 公共參數的全域提示詞旁提供「重新生成全域提示詞」。可填修改要求，以目前已儲存文字或本瀏覽器未儲存草稿為起點；Astra 生成一份持久候選，完成後比較、再明確採用。等待、失敗及已完成狀態會在重新載入後保留，活動記錄也可開啟歷史比較。

此功能只更新選定 Scene 的共用提示詞。保留 Subject／Picture 對應，重寫共用人物外觀、場景材質、光線及環境；道具定義和鏡頭動作仍屬於各 Shot。原作人名保留原文，場景及物件名稱使用英文。採用時保存此 Scene 每個有效 Shot 提示詞，避免原有整場生成結果失效後回落到較舊文字；其他 Scene、canon、媒體、production revision 不變。

`h3_global` 沿用持久工作及 Astra 預設路由，可切換服務商。提交前須已完成 Scene 英文整理，但缺少圖片不阻擋文字生成。候選須通過共用引用／對應、單一 subject_definitions、英文、每個完整 Shot 六段格式及總長度驗證；全域禁止對白，原有 Shot 的獨立人手對白修改逐字保留，其原分鏡差異繼續由 Shot issues 顯示。任何 Scene 來源、Shot 文字或參考圖改動均令未採用候選過期；採用時再次驗證。生成期間再改的本瀏覽器全域草稿亦不會被覆蓋。重複採用同一結果不新增修訂。
