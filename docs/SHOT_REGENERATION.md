# 重新生成單一 Shot 分鏡提示詞

每個 H3 / Ref2VA Shot 的提示詞工具列提供「重新生成分鏡提示詞」。可填修改要求，也可留空讓 Astra 依既定分鏡改善清晰度。尚未儲存的文字可作修改起點，原草稿保留。

只生成文字候選，完成後顯示「比較新版」。採用前不變動現行提示詞、劇情、Scene 公共參數、其他 Shot、圖片或配音。比較視窗並列修改起點與新版，按「採用新版」才寫入原有 delivery 設定及修訂記錄。產生失敗可重試；進行中禁止重複送出。重新載入頁面亦能找回工作狀態與候選，活動記錄保留歷史結果。

`h3_shot` 使用既有持久工作、Astra 預設路由及可切換服務商。輸入凍結本鏡、前後鏡邊界、相關身份、共用提示詞、圖片編號、已保存文字及使用者編輯起點。只重新生成一個 Shot，無需所有參考圖先完成，但本 Scene 的英文準備必須已完成。輸出沿用六段 Ref2VA 結構、原作人名、對白及圖片編號，含本鏡道具定義。

採用時重新比對當前本鏡、公共參數和參考圖，拒絕把過期方案蓋過新內容；其他 Shot 的獨立文字修改保留。若使用者生成期間又改了瀏覽器草稿，前端亦拒絕覆蓋。重複採用同一結果不新增重複版本。生成與採用不改 production revision。

驗證涵蓋草稿輸入、重複提交、完成前不覆蓋、明確採用、其他 Shot／公共參數／素材保留、匯出結果、過期及跨作品拒絕、錯誤對白／引用標籤拒絕和圖片未完成時的文字生成。完整 Python suite 216 passed；最後補共用原作人名案例後六項 focused tests passed。JS 覆蓋生成、等待、失敗、比較與採用狀態，既有 Director／草稿編輯／Shot 參考檢查亦通過。
