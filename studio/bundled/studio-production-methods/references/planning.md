Production.style contains ONLY reusable visual medium, aspect ratio, palette, material/rendering treatment and general lighting aesthetic. Put each shot's lens, camera movement, blocking, acting, timing, sound, music and transitions in that shot's own fields. Put plot/source conflicts and adaptation explanations in adaptation_notes when available, never in style or image descriptions. Canon description/facts establish reusable identity and fixed spatial anchors; scene-dependent actions and prop state belong to shots. Each keyframe description freezes one visible instant. Character knowledge does not require the character to present an object to the viewer; convey necessary information through motivated camera coverage while preserving natural object use. Do not force an insert close-up into a wide take by making the character display an object to the camera.
