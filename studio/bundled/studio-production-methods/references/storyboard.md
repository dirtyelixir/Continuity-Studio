# Visual storyboard production

Studio decides the editorial sequence using the adopted Director Plan, visual-skills dramaturgy and montage reasoning. Image demand follows generation need, not narrative beat count. In generation-needed-images-v2, use the shared ConditioningDecision with h3_strategy: I2VA for a composed opening, FL2VA for an explicit ending constraint, or REF2VA for necessary reusable identity/object/appearance/environment references. Preserve an already adopted conditioning decision. REF2VA has anchors: [] and explicit reference_demands; Studio resolves only required shot-scoped approved canon assets and assigns slots. Optional references are omitted by default. Missing required assets and unsupported media demands block submission. Never select by storyboard count, trims, or the scene-wide canon union. Legacy v1 retains I2VA/FL2VA only. Keep ordinary acting, motion and review-only beats as text planning_notes. The executor generates the full source, so its conditioning opening/ending may lie outside the editorial trim; label these as source constraints, never as pictures of the selected cut-in. Repeated editorial uses share the same source strategy and image targets. Legacy boards retain their original exact edit-in anchors and review history.

A source/editorial Shot remains one continuous camera source; a Storyboard Frame is a still; a Generation Segment is a provider execution interval. Their counts are independent. An interior key does not create a cut or become an automatic FL2VA endpoint. Changes of independent camera setup remain separate source Shots in the adopted edit sequence. Only explicit H3 generation groups may execute multiple adopted views in a native clip. Same-shot internal segmentation requires a supported execution/timing/assembly contract; the current single-source route does not implement it. If a hard intermediate constraint requires that unsupported route, return an unresolved constraint before spending on another image. Do not pretend Ref2VA reference images enforce exact timestamps, or that independently generated segments join seamlessly.

Every image is one still at one instant, not a contact sheet. The interface arranges these separate originals as an ordered board for human review. Reuse an existing frame only for the same source and exact time/state. Identity references cannot substitute for an actual view composition. The board planner does not rewrite existing frame descriptions, source direction, dialogue or reveal order. Route an incompatible required setup back to director revision.

Decide image-conditioning strategy → inspect/adopt strategy and required frames → prepare only missing required images with the configured renderer → review those images → compile H3 inputs → inspect generated footage. Human panel approval is bound to the current source and exact image bytes; replacing a picture or changing the plan requires renewed review. A text arrangement and an approved still do not prove cut timing, movement or generated-film quality. I2VA/FL2VA native groups may use a reviewed interior frame at their exact selected outer boundary; never use an original opening image for a trimmed native boundary at another time. Ref2VA may use role-labelled identity and composition images within the actual supported limit, when references are actually needed, not to consume a backlog of storyboard images.
